# Retail Revenue & Profit Intelligence | Awanish Mishra

A Power BI **starter project** featuring independently generated synthetic retail data, profitability analysis, regional trends and customer analytics.

## Dashboard plan
1. Executive Pulse — revenue, profit, orders, margin and channels
2. Product & Margin Lab — category performance and discount analysis
3. Regional & Customer Lens — regional sales and customer KPIs

## Included files
- `awanish_retail_sales.csv`: synthetic demo dataset
- `DAX_measures.txt`: Power BI measures and date table
- `theme.json`: custom Midnight Teal theme
- `dashboard_preview.png`: conceptual preview, not an actual Power BI screenshot
- `BUILD_GUIDE.md`: steps to assemble the report in Power BI Desktop

**Note:** No native PBIX has been produced yet. The original dataset is synthetic, not a real retailer's data.

## Inspiration
General inspiration from [Sachin Kumar's Power BI examples](https://github.com/sachinkumar1609/PowerBI-Project). This project uses a separate synthetic dataset and original analysis structure.
